![Main Dashboard]
(Dashboard ipl_analysis.png)

## 📌 Overview
Analyzed 700+ IPL matches from 2008-2025. Cleaned raw data and built an interactive dashboard to find winning patterns, venue analysis, and player performance.

## 📂 File Structure
This repo has 1 Excel file with 7 sheets:
- `ipl dataset project`: Raw data - team1, team2, toss_winner, winner, venue, player_of_match
- `titlewinner`: Year-wise Winner, Runner-up, Player of Final, MVP (2008-2019)
- `MATCHES WON BASED ON TOSS`: Team-wise Bat First vs Bowl First Wins
- `toss decision`: 83% Field vs 17% Bat decision analysis (Donut Chart)
- `TOP 10 VENUES`: Top venues with most matches & win split
- `MOM`: Most Man of the Match winners
- `DASHBOARD`: Final Interactive Dashboard with Season Slicer

## 🛠️ Tools Used
Excel - Power Query, Pivot Table, Slicers, VLOOKUP, TRIM, IF, Charts (Bar, Donut, Treemap)

## 📊 Key Insights
- 83% Teams choose to FIELD after winning toss
- CSK & MI - 5 Titles Each (Highest)
- Rajiv Gandhi Stadium hosted most matches
- Top MOM: AD Russell (4 times)



## 🔗 How to View
Download `IPL_Data_Analysis 2008-2025.xlsx` -> Open `DASHBOARD` sheet -> Use Season filter IPL-2019 etc.
